how to perform rate limiting 

To enable rate limiting in Nginx, you use:

limit_req_zone → defines the rate limit

limit_req → applies it to a location or server

Here’s how to do it properly.

✅ Basic Rate Limiting (Per IP)
1️⃣ Add this inside your http {} block
limit_req_zone $binary_remote_addr zone=api_limit:10m rate=10r/s;

What this means:

$binary_remote_addr → limit per client IP

zone=api_limit:10m → shared memory zone (10MB storage)

rate=10r/s → 10 requests per second per IP

2️⃣ Apply it inside a server/location block

Example for your Node app on port 3000:

server {
    listen 443 ssl;

    ssl_certificate /etc/nginx/ssl/nginx.crt;
    ssl_certificate_key /etc/nginx/ssl/nginx.key;

    location / {
        limit_req zone=api_limit burst=20 nodelay;

        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
🔎 What burst and nodelay Do

burst=20 → allows 20 extra requests temporarily

nodelay → processes burst immediately instead of delaying

Without burst, traffic gets rejected instantly when exceeding 10r/s.

🚀 More Realistic Production Setup

Example:

limit_req_zone $binary_remote_addr zone=api_limit:20m rate=5r/s;

Then:

limit_req zone=api_limit burst=10;

This means:

5 requests per second

Can temporarily spike to 15

After that → 503 error

🔐 Optional: Custom Error Message

Add inside http {}:

limit_req_status 429;

Now instead of 503, clients get:

429 Too Many Requests

(More correct for APIs.)

📌 Test After Adding

Always test:

nginx -t

Then restart:

systemctl restart nginx
